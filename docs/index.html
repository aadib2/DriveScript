🚗 DriveScript

An Esoteric Programming Language Inspired By Driving Actions

What is DriveScript?

DriveScript is an esoteric programming language that blends the syntax of driving commands with computational logic. Instead of traditional programming constructs, DriveScript uses driving metaphors—shifting gears, accelerating, and honking—to manipulate memory cells and produce output.

Created as part of SDSU CS 420: Advanced Programming Languages, by mapping driving primitives to a minimal Turing-complete instruction set, DriveScript demonstrates that real-world physical actions can serve as syntax, which opens the door to some cool applications! Note: DriveScript is not optimized for production coding applications.

How It Works

Core Concepts

DriveScript operates on an array of memory cells, similar to Brainfuck. You navigate through these cells and manipulate their values using driving-themed commands.

Basic Syntax

RIGHT Move the pointer one cell to the right
LEFT Move the pointer one cell to the left
GAS Increment the current cell by 1
BRAKE Decrement the current cell by 1
GEAR N Repeat next action n times
GEAR R Invert next action
HONK Output the ASCII character of the current cell's value
LISTEN Read a byte from user input into the current cell
PARK ... DRIVE Loop block: repeat while current cell is non-zero

Example Program

Here's a simple DriveScript program that outputs "Hi":

# Set cell 0 to 72 (ASCII for 'H')
GEAR 5 GAS GEAR 5 GAS # cell 0 = 10

PARK
    RIGHT GEAR 5 GAS GAS GAS # cell 1 += 7
    RIGHT GEAR 5 GAS GEAR 5 GAS # cell 2 += 10
    GEAR 2 LEFT # go back to counter
    BRAKE # decrement
DRIVE

# Set cell 1 to '72' (ascii for 'H'), output, and move to next cell
RIGHT GAS GAS HONK RIGHT
# Set cell 2 to '105' (ascii for 'i'), output
GEAR 5 GAS HONK
# go back to cell 0
GEAR 2 LEFT
Output:
Hi
